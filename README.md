`csv2xyd` is a user-friendly, Python-based software featuring a Graphical User Interface (GUI) designed to streamline the preprocessing, filtering, and conversion of large biodiversity distribution datasets from standard tabular formats (`.csv`) into the specific matrix formats required for quantitative endemism analysis, such as **XYD** and **TNT** formats used by **NDM/vNDM**.

Biodiversity repositories (e.g., GBIF) often provide massive datasets containing taxonomic inconsistencies, typographical errors, and duplicate geographic records. `csv2xyd` resolves these bottlenecks using high-performance computing strategies, enabling researchers to clean and structure millions of occurrence records efficiently.

## Key Features

- **Robust Preprocessing & Cleaning:** Automatic detection and removal of coordinate duplicates, handling of invalid spatial data, and identification of typographical errors using fuzzy string matching.
- **Multiple Input Workflows:**
  - **Semi-Formatted CSV:** Streamlined ingestion of localized or custom tables containing essential columns (species, latitude, longitude).
  - **Biodiversity Repositories:** Specialized data parsers tailored for large-scale standard exports (e.g., GBIF), allowing interactive column mapping and taxonomic group filtering (e.g., *Amphibia*, *Arthropoda*).
- **Data Integration & Sorting:** In-app features to merge multiple heterogeneous datasets and sort them hierarchically by genus and species.
- **High-Performance Scaling:** Powered by `Dask` and `Pandas` for optimized out-of-core memory management, capable of handling hundreds of thousands of rows smoothly.
- **Spatial Validation:** In-app mapping and geographic data validation built over `GeoPandas` and `Folium`.
- **Ready-to-Use Outputs:** Directly exports clean cross-tabulated tables, standard `.xyd` spatial point matrices, and `.tnt` files fully compatible with NDM/vNDM default limitations.

## System Requirements & Dependencies

### Hardware Recommendation
- **Minimum:** 8 GB RAM.
- **Recommended:** 16 GB RAM or higher when processing massive regional or global biodiversity data repositories (e.g., >750,000 occurrence records).

### Software Requirements
- **Python 3.12.4** or higher.
- Core dependencies detailed in `requirements.txt`:
  ```text
  tkinter
  pandas>=2.2.2
  dask>=2024.7.0
  fuzzywuzzy>=0.18.0
  folium>=0.17.0
  numpy>=2.0.0
  geopandas>=1.0.1
  shapely>=2.0.5
